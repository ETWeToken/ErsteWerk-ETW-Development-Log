# ErsteWerk-ETW-Development-Log
Public development log for the ErsteWerk recruitment platform, ETW ecosystem and eToken Miner app. Progress, technical notes and project milestones — no source code.

ErsteWerk is not a project that was created in a single day. The portal has developed step by step from the first versions of the recruitment platform, through new features for candidates and recruiters, to the integration of the portal with the ETW ecosystem and the eToken Miner application.

Many elements of this work only become visible to users once they are ready. Behind a single feature, however, there may be weeks of testing, changes, failed attempts, analysis and technical decisions. There are also things that users will practically never see: security work, analysis of unusual traffic, technology migrations, payment testing or observing how the system behaves after deployment.

This is exactly why this repository was created.

This is not a public source code repository for ErsteWerk or the ETW application. It is a public development log of the project.

We want to document here, among other things:

the development of the ErsteWerk recruitment platform,

the development of the ETW ecosystem and its utility,

the development of the eToken Miner application,

important tests and deployments,

problems we encounter during development,

technical observations and conclusions,

the most important project milestones.


Not every experiment ends in deployment. Not every hypothesis turns out to be correct. Sometimes solving one problem leads to another question. This log is intended to show this part of the project's development as well not only the finished result.

What We Do Not Publish Here

Transparency does not mean publishing everything.

This repository will not contain the project's source code, user data, access credentials, keys, production configurations, or security details whose disclosure could weaken the protection of the system.

The goal is to show how the project develops, not to expose its infrastructure.

The Project Is Still Being Developed

ErsteWerk, ETW and eToken Miner are actively developed components of one ecosystem. Therefore, this log is not a finished document either.

It will develop together with the project.
